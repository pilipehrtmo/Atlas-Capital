# Example data

`brent-monthly.csv` and `wti-monthly.csv`: U.S. Energy Information Administration Brent and WTI spot prices, monthly averages in USD per barrel, through September 2026. Retrieved 25 Oct 2026 from the [datasets/oil-prices](https://github.com/datasets/oil-prices) mirror of the EIA series (EIA data is public domain). Production ingestion will read the EIA API directly.
